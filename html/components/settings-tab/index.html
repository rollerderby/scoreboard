General Settings
When only one name is set, that one will be used.
NSO screens will use Uniform Color when set and fall back to this otherwise. When only one name is set, that one will be used.
Sanctioned games require "Full Name".
Supported Variables:
%g: Game Number
%G: "Game <Game Number>: " if game number is set, empty otherwise
%d: Date of Game
%t: Start Time
%1: Team 1 Name
%2: Team 2 Name
%s: Game State
%S: "<Team 1 Score> - <Team 2 Score>"
This expects a path relative to the base folder of CRG.
Triggers when the lineup clock reaches the configured duration and "Five Seconds" has not been marked. Triggers when the lineup clock reaches the configured duration and "Five Seconds" has been marked.
