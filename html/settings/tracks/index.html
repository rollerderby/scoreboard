Tournament on Several Tracks
One scoreboard is the tournament server: the games are prepared there. The scoreboard of each track pulls its games from the tournament server and sends them back while they run, so the tournament server always has every game. When a game is over and its paperwork checked, the track hands it over, so it can be reviewed and its statsbook made on the tournament server while the track runs the next game. With a single track none of this is needed.

While a track runs a game, the game can only be changed on that track's scoreboard. Release lets another track pull it, e.g. when a track's laptop broke down; the game is then as this scoreboard last received it.

A pulled game goes on this scoreboard. Between jams it is sent to the tournament server whenever it has changed; while the tournament server can't be reached, it is tried again every few seconds, and nothing is lost. During a jam, the tournament server shows the clocks and the score this scoreboard reports. Once the paperwork has been checked, Hand Over (also on the IGRF tab) sends the game to the tournament server for review; it can't be changed here any more after that. Take Back pulls it back with any changes made there.
